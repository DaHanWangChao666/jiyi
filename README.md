# 记忆修复局

一个可以直接在浏览器里玩的轻量网页游戏。

**在线游玩**：<https://dahanwangchao666.github.io/jiyi/>

---

你是一个刚入门的修士。

**每一次行动都在消耗寿元** —— 修行、探索、办事、静养，做什么都要拿命换。

一局可以一路修到渡劫，也可以随时下山做一个散修，去山里采药、钓鱼、种地。

---

- 纯 HTML + CSS + JavaScript，**零依赖、零构建**
- **单文件**，完整游戏都在 `index.html` 里（约 384 KB）
- 支持**手机与电脑**，竖屏优先
- 进度保存在浏览器本地（`localStorage`），关掉网页再打开还在

## 特色

- **寿命即资源** —— 每一次点击都在烧命，这是全部的紧张感来源
- **多世界观** —— 《宗门》是第一个，后面还有《活着》与《零点频率》
- **六维属性** —— 体魄 / 灵力 / 悟性 / 身法 / 神识 / 根骨
- **卡牌构筑 + 流派套装** —— 剑修 / 符箓 / 外丹 / 夺道 / 体修
- **失败转盘** —— 打输了不一定死，但扇区大小由你的属性决定
- **隐藏内容** —— 隐藏 Boss、隐藏结局、以及一条贯穿全局的世界线
