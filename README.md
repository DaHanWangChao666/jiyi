# 《记忆修复局》

一个可以直接在浏览器里玩的轻量网页游戏。

> **你在三个不同的世界里生存，然后在局外把这些碎片拼起来。**

- 纯 HTML + CSS + JavaScript，**零依赖、零构建**
- **单文件**：整个游戏都在这个 `index.html` 里（约 1.3 MB），下载下来双击就能玩
- 支持手机与电脑，竖屏优先
- 进度保存在浏览器本地（`localStorage`），关掉网页再打开还在
- 游戏内可导出存档成一段字符串带走

> ⚠️ **这个仓库里只有打包产物。** 源码与设计文档在另一个本地仓库里，
> 由 `build.js` 打包后推到这里。所以**不要直接改这个 `index.html`** —— 会被下一次打包覆盖。

## 玩法

你是一个刚入门的修士。

**每一次行动都在消耗寿元**——修行、探索、办事、静养，做什么都要拿命换。
境界越高，寿元上限越高，但单次行动的消耗也越大。突破会发放一大笔寿元。
一局没有固定长度：你一直行动到寿元耗尽、主动收束，或者触发某个结局。

**当前版本锁在元婴。** 完整境界表有 38 档（炼气 9 档 + 筑基起 7 个大境界各 4 段 + 渡劫 1 档），
但内容只铺到元婴，所以玩家这一世能走的是 **21 档**，走到头是「此世圆满」。
渡劫在境界表里存在，但那一章还没做。

### 三条路线

| | 你在哪 | 你做什么 |
|---|---|---|
| **宗门篇** | 山门里 | 修行、宗门事务、藏经阁、职衔、月俸、主线《三月初七》 |
| **散修篇** | 山野间 | 采药、钓鱼、种田、云游、洞府、六门技艺、四季轮转 |
| **舆图 · 远行** | 七个寰 | 花寿元走去别处：北冥剑冢（冰原）、白鹿书院（书山）、万药谷（药洲）…… |

宗门散了不是结局，是开场。你也可以随时主动下山。

### 六维属性

**体魄 / 灵力 / 悟性 / 身法 / 神识 / 根骨**——三项成长来源：开局抽签、每次突破、机缘。

六项对普通攻击与招式威力的贡献是**相同的**（那吃的是六维总和），
差别在于各自的专属作用：体魄扛冰原的严寒、灵力管交涉、悟性管读碑抄录、
身法让赶路更省寿元、**神识能发现藏起来的地方**、根骨扛药毒与长途。

堆哪一项，真的会改变你怎么玩。

### 藏起来的东西

三个世界观里，藏着**同一个东西**。

注意到不对的地方，记得多看一眼。

## 常见问题

**打开是一片乱码 / 显示的是代码？**
缺少 `.nojekyll`（本仓库里有，正常情况下不会遇到）。

**我刷新了但界面没变？**
浏览器缓存。按 `Ctrl + Shift + R` 强制刷新。

**存档会丢吗？**
存档在每个玩家自己的浏览器里。同一个浏览器 + 同一个网址，进度就在。
换设备或清除浏览器数据会丢——用游戏内的「存档搬移」导出成字符串可以带走。

**手机打开排版乱？**
已经做了移动端适配（viewport + 响应式 + 刘海屏安全区）。如果还是乱，请反馈。
